# 南京城市手绘卷轴 · 2026 EL 智能应用开发与创新大赛

一款融合了手绘水墨美学、高德地图交互、AI 助手的南京城市探索 App。

## 🎨 核心特色

- **水墨开屏动画** — 五幕手绘场景卷轴式展开，GSAP 驱动的视差交互
- **8 种人格选择** — 美食家、文学爱好者、夜游玩家…每种人格对应不同的地图风格与路线推荐
- **高德地图集成** — 基于 AMap JS API 2.0，支持 3D 视图、手势缩放拖拽、路线绘制
- **4 条精品路线** — 南大校史线 / 秦淮夜游 / 午后餐茶 / 博物馆展览，含剧情节点故事
- **美团 API 集成** — 实时 POI 搜索、商家详情、优惠券，让路线贴合实际消费场景
- **AI 南小鲸助手** — 对话式路线推荐，回答南京吃喝玩乐问题
- **路线复刻系统** — 复刻路线 → 修改为我的版本 → 生成邀约卡
- **0520 南大剧情游戏** — 基于 Three.js 的交互式叙事游戏覆盖层

## 🔧 技术栈

- **前端**: 纯 JavaScript (无框架) + GSAP 动画 + Three.js
- **地图**: 高德地图 JS API 2.0
- **后端**: Spring Boot 3.3.5 (Java 17)
- **数据**: 美团 API (POI 搜索 / 商家详情 / 优惠券)
- **AI**: 南小鲸对话 API
- **移动演示**: iPhone 风格手机框 iframe 嵌套

## 🚀 启动方式

```bash
# 进入源码目录
cd 主app代码/2026EL-main

# 启动 Spring Boot 应用
mvn spring-boot:run

# 访问
# 主应用: http://localhost:8080/app/index.html
# 移动端演示: http://localhost:8080/mobile-demo/index.html
```
