# 南京城市周末出行 + 南大新生校园漫游剧情 APP 前端视觉设计规范

## 1. 整体风格定位

产品定位为面向大学生、南大新生、年轻出游群体的城市漫游与剧情导览 APP。整体视觉应体现“清新、治愈、轻剧情、轻二次元、金陵文化感”。

设计关键词：

- 城市漫游：轻地图、轻路线、低压力出行
- 剧情沉浸：章节式推进、文字电影感、点位任务反馈
- 南大校史：校园记忆、百年时间线、温柔叙事211111
- 周末闲逛：松弛、陪伴、适合单人 / 好友 / 约会场景
- 轻二次元：虚拟向导陪伴，但不过度游戏化

视觉气质：低饱和、明亮、干净、有文化细节，不做重度国风，不做高饱和动漫风。

## 4. 视觉元素规范

### 插画风格

采用“轻国风 + 城市手账 + 二次元向导”的混合风格。

插画元素：

- 南京：城墙、秦淮河灯影、梧桐、夫子庙屋檐、老门东街巷
- 南大：北大楼、鼓楼校区、校史时间轴、校园树影
- 周末闲逛：咖啡、书店、地图贴纸、拍照打卡、展览票根
- 向导角色：小型半身立绘或头像气泡，不遮挡主内容

插画不要过满，不做复杂背景大图堆叠。优先作为页面局部点缀、空状态、剧情弹窗角色形象。

### 图标风格

图标使用线性圆角风格，线宽 1.8px - 2px。图标语义清晰：

- 路线：地图针、路径、指南针
- 剧情：书页、卷轴、对话气泡
- 展览：票券、建筑、铃铛
- 成就：徽章、星标、印章
- AI 向导：对话、魔法棒、耳机

### 卡片与布局

- 卡片圆角：8px
- 按钮圆角：8px
- 标签圆角：999px
- 页面左右边距：16px
- 卡片内边距：14px - 16px
- 模块上下间距：20px - 28px
- 卡片阴影：轻阴影，不使用厚重投影

推荐阴影：

```css
box-shadow: 0 6px 18px rgba(38, 50, 56, 0.08);
```

## 5. 动效与交互氛围

整体动效应轻、慢、柔，不追求强游戏感。

- 页面切换：200ms - 280ms，轻微上滑 + 淡入
- 路线卡片点击：卡片轻微缩放 `scale(0.98)`
- 剧情翻页：纸页淡入、文字逐行出现
- 任务完成：徽章轻弹出，伴随柔和光晕
- 预约提醒：铃铛轻摇动效，不闪烁
- 向导弹窗：从底部上浮，角色头像先出现，对话气泡随后出现

剧情文字建议支持“逐字出现”效果，但要提供跳过/快速显示能力。

## 6. 关键页面定调

### 开屏页

视觉重点：南京城市轮廓 + 南大校园元素 + 柔和品牌色。

内容建议：

- Slogan：`今天，去南京走一段故事`
- 背景：秦淮河水纹、梧桐影、城市线稿
- 动效：轻微水波或纸张淡入

### 心情 / 身份选择页

用于收集推荐条件。

身份选项：

- 南大新生
- 一个人闲逛
- 和朋友出门
- 约会出行
- 展览爱好者

心情选项：

- 想放空
- 想热闹
- 想拍照
- 想学点历史
- 只有两小时

选项用图标 + 短文字卡片，选中态使用主品牌色描边和浅色填充。

### 首页

首页应直接进入功能，不做营销页。

模块顺序建议：

1. 今日适合出发
2. AI 帮我安排
3. 按时间选路线
4. 生活路线 / 文化路线
5. 南大专属
6. 热门复刻
7. 展览预约提醒

首页顶部保留小型二次元向导头像，可显示一句轻提示，如“今天想走轻松一点，还是去听一段城市故事？”

### 路线卡片页

卡片信息必须清晰：

- 路线名
- 适合人群
- 预计时长
- 步行强度
- 预算
- 标签
- 是否需要预约
- 剧情完成度

卡片左侧可用路线主题色条区分类型。生活路线偏清新绿，文化路线偏青瓷蓝，南大路线使用低饱和紫，夜游路线使用深蓝 + 灯色点缀。

### 剧情导览页

采用章节式沉浸阅读。

结构：

- 顶部：路线名 + 当前章节进度
- 中部：剧情文本 / 建筑介绍 / 任务内容
- 底部：向导气泡 + 操作按钮

任务类型表现：

- 单选题：选项卡片
- 拍照打卡：相机按钮 + 示例提示
- 找线索：关键词高亮
- 情绪选择：情绪标签按钮
- 感想提交：短文本输入框

### 成就页

风格类似“城市文化图鉴”。

- 未解锁：灰色线稿徽章
- 已解锁：柔和金色徽章
- 成就详情：显示解锁来源路线、完成时间、文化说明

成就页不做强竞技排名，突出收藏感和纪念感。

### 南大专属剧本页

视觉关键词：校园、校史、时间线、二次元向导。

设计建议：

- 时间轴从 1902 延伸到 2026
- 每个节点对应建筑、故事、互动任务
- 向导角色语气更温柔、陪伴感更强
- 背景使用浅纸张色 `#F7F1E8`，搭配南大紫点缀

### 展览预约卡片页

信息优先级：

1. 展览 / 场馆名称
2. 开放时间
3. 预约规则
4. 放票时间
5. 官方入口
6. 设置提醒

预约提醒按钮使用铃铛图标。官方入口按钮保持明确，不让用户误以为 APP 可以直接替代官方预约。

## 7. 多场景 UI 氛围区分

| 场景 | 视觉氛围 | 色彩 |
|---|---|---|
| 单人放空 | 安静、留白、轻文字 | 青瓷绿 + 纸白 |
| 好友闲逛 | 明快、卡片感、路线分享 | 青绿 + 暖黄 |
| 约会路线 | 柔和、浪漫、低饱和 | 暖粉 + 灯色 |
| 南大校史 | 校园、时间感、书卷气 | 纸张色 + 南大紫 |
| 金陵夜游 | 沉浸、夜色、灯影 | 深蓝 + 柔金 |
| 展览路线 | 清晰、理性、信息卡片 | 白底 + 青瓷蓝 |

## 8. 前端落地建议

移动端优先设计，推荐宽度按 `375px / 390px` 设计稿适配。电脑网页演示时可做一个居中的手机模拟器容器，最大宽度 `430px`，方便答辩展示。

组件优先级：

- `RouteCard` 路线卡片
- `MoodSelector` 心情选择
- `GuideBubble` 二次元向导气泡
- `StoryChapterCard` 剧情章节卡
- `TaskPanel` 任务面板
- `AchievementBadge` 成就徽章
- `ExhibitionCard` 展览预约卡
- `InviteCard` 邀约卡

整体目标：界面像一个“会陪你逛南京的轻剧情手账”，而不是传统旅游攻略软件。
